USB 双向映射 — UsbSync1
贡献者：GPT-6 Astra（AI 辅助开发），2026-10-30

使用方法
1. 两台 Windows x64 电脑分别安装本次 Moonlight 与 Sunshine 安装包。
2. Moonlight 主机列表中右键已配对、在线的电脑，打开“双向 USB 设备映射”。
3. 两端首次使用均需安装 USB 组件：本机可点击 USB 窗口中的安装按钮；远端可运行 Sunshine 安装目录 USB\Install-USB.ps1（右键“使用 PowerShell 运行”）。脚本会请求管理员权限。
4. 远端 Sunshine 网页设置 → 输入 → USB 设备转发（实验性），启用后保存并重启 Sunshine。远端共享/取消共享需要 Sunshine 以管理员或服务方式运行；参见高权限开机自启说明。
5. 在 Moonlight USB 窗口点击刷新，按需要选择：
   “本机 USB → 远端”：将插在 Moonlight 电脑上的设备交给 Sunshine 电脑。
   “远端 USB → 本机”：将插在 Sunshine 电脑上的设备映射到 Moonlight 电脑。
6. 对具体设备点击“共享”，再点击“连接”。两个方向可同时使用不同设备；不会自动连接所有设备。
7. “释放”结束该连接；“全部释放”只处理本窗口建立的连接。关闭 USB 窗口也会释放这些连接。“取消共享”撤销设备的持久共享设置。

窗口与设备行为
- USB 管理窗口独立于串流窗口运行，切换焦点或退出视频串流不会自动关闭 USB 连接。切回本机即可操作 USB 窗口；再次从主机菜单打开会激活同一窗口。
- 一个 USB 设备同一时刻由接收方独占。存储设备释放前先结束写入、关闭使用它的程序；不要在传输中拔线。
- 不按设备类型做白名单限制，但并不保证所有 USB 设备兼容。存储、打印机、串口、键鼠、手柄、摄像头和声卡均交给 USB/IP 驱动枚举。等时传输、高带宽、专用驱动、复合设备和设备重置行为可能影响摄像头/音频等设备。
- 不使用强制绑定。驱动拒绝共享的设备会显示失败，保留原驱动。接收方仍可能需要安装该设备原厂驱动。
- 不要把当前唯一的键盘或鼠标交给另一端后失去本机操作入口。
- 断线后关闭隧道并清理本次导入；不会静默重新接管设备。重新连接需用户再次选择。
- 软件更新检查仍禁用。USB 组件只在点击安装或手动运行安装脚本时安装固定版本。

组件与网络
- 共享端：usbipd-win 5.3.0，https://github.com/dorssel/usbipd-win/releases/tag/v5.3.0
- 导入端：usbip-win2 0.9.8.1，https://github.com/vadimgrn/usbip-win2/releases/tag/v.0.9.8.1
- 安装脚本从官方发行页下载，验证固定 SHA-256 和有效 Authenticode 签名。安装包本体不捆绑第三方驱动。离线安装可把同名官方 MSI/EXE 放在 USB 脚本旁，仍须通过相同校验。
- 不更改 Secure Boot，也不启用测试签名。组件版本高于固定版本时不降级。
- 两个方向都由 Moonlight 主动连接 Sunshine：设备列表和共享操作使用配对 HTTPS；USB 数据走双向证书认证的 TLS，默认端口 47996（主端口 +7）。修改 Sunshine 端口后以实际设置为准。
- 两端 USB/IP 服务仅通过本机回环 127.0.0.1:3240 被使用。安装脚本会说明并建立规则，阻止其他电脑直接访问未加密的 TCP 3240；使用 WSL/其他直接 USB/IP 方案的用户应理解这会影响其直接网络连接。
- 无需在 Moonlight 所在电脑向网络开放 USB 端口。Sunshine 所在电脑需允许客户端访问配置的 TLS USB 端口。

验证范围
已通过两个软件 Release 编译、Qt 双向 TLS 大数据与断开排空测试、错误证书拒绝、Sunshine 设备 ID 限制/错误令牌拒绝/连接槽释放重用，以及 USB 界面离屏渲染。
没有在两台电脑之间接管真实 USB 设备；上述测试使用隔离的模拟 USB/IP 端点，不能证明每种 USB 硬件、驱动或网络环境兼容。
