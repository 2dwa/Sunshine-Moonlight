Moonlight / Foundation Sunshine 焦点切换、锁定键与剪贴板同步修改版
2026-10-30，Windows x64，非官方版本

一、安装与启动
1. 本机安装 Moonlight-Focus-Setup-x64.exe；远端安装 Sunshine-Focus-Sync-Setup-x64.exe。
   也可以将相应 ZIP 解压到独立目录使用。
2. 安装器采用独立目录，不覆盖已有 Moonlight 或 Sunshine，不自动切换正在运行的服务。
3. 远端必须退出原 Sunshine（包括原 Sunshine 后台服务），再启动修改版 sunshine.exe。
   现有驱动可以继续使用。确需注册服务或补装驱动时，在新目录手动运行原版 install_portable.bat。
   不要同时运行两个 Sunshine 实例。升级前备份原 Sunshine 配置。
   本次修复后，直接双击 sunshine.exe 或开始菜单快捷方式启动，不再创建命令行窗口。
   日志仍可在控制面板查看；命令行参数和输出重定向保留。安装/卸载驱动用的 BAT 属于维护工具。
   已修正无控制台模式下的重启判断：独立运行可正常重启，服务模式由原有服务监督程序重启。
4. 本机从安装器创建的开始菜单快捷方式启动，或运行 Start Moonlight.cmd。
   新客户端使用独立便携配置，首次使用需添加远端电脑并重新配对。
   本次安装器覆盖升级已有修改版时保留 Moonlight.ini（包括配对和快捷键）。ZIP 请解压到新目录。

二、操作
安装包预设 Alt+Q，在设置 > 输入设置 > “本机 / 串流焦点切换”中可以重新录入。
允许 Ctrl 或 Alt + 字母、数字、F1–F24，可附加 Shift。
松开组合键后才切换，长按不会反复切换；串流开启“捕获系统快捷键”时也走独立识别路径。
切回本机会释放远端键盘和鼠标按键，恢复本机鼠标位置并尝试激活上次本机窗口。
切回串流恢复记录的鼠标位置；目标位置显示黑白交替的鼠标形提示，持续约 0.5 秒。
首次从串流返回时，如尚未记录另一块屏幕的位置，默认落到另一块屏幕中央。
客户端预设无边框全屏、远程桌面鼠标模式，适合双屏办公；原有客户端的个人设置不被改写。

三、锁定键同步
以运行 Moonlight 的本机为准：Caps Lock、Num Lock、Scroll Lock。
连接建立、进入串流、锁定键变化和串流期间每秒会向支持本扩展的 Sunshine 发送目标状态。
消息沿用串流的可靠加密输入通道，无额外监听端口；远端只切换状态不同的键。
此功能需要本次客户端和服务端配套使用；连接旧服务端时自动停用状态同步，普通输入照常工作。
远端若处于不可访问的安全桌面、物理锁定键仍按住或系统拒绝注入，会在下一次更新重试。

四、适用范围与验证边界
远程桌面鼠标模式能保存本机与串流画面中的绝对位置。
游戏相对鼠标模式不主动移动远端鼠标，保留远端自身位置；由于传统协议不回传游戏光标位置，提示显示在画面中心。
提示采用临时鼠标形叠层，不替换系统鼠标主题。独占全屏或特殊硬件叠层可能遮挡提示，建议无边框模式。
本版本编译和独立逻辑测试可在随包测试记录中查看；真实双机串流、显示器 DPI、远端提权窗口等仍需实机验收。
本次构建保留所选 Foundation Sunshine 版本的原有源码功能和官方包中的驱动、工具、插件及许可证。
RTX HDR 和 DLSS NR 均已编译启用，使用该版本官方包的适配器，并保留原版适配器/运行库哈希校验。
这两项仍需兼容的 NVIDIA 显卡、驱动，以及原版控制面板要求的 NVIDIA 运行库；运行库不会被绕过或伪造。
GPU 实际画质与性能尚未在远端机器验证。可在原版增强设置中启用和配置。

五、双向文本与文件复制
本机设置 > 输入设置 > 本机 / 串流焦点切换 > “双向复制文本和文件（仅串流期间）”，默认开启。
Sunshine 原有 clipboard_sync 开关同样有效，关闭后不允许此功能。
开始串流后，在任意一端 Ctrl+C，另一端收到后即可 Ctrl+V；文件夹、多文件和空文件均支持。
文件先完整传输到接收端缓存，完成后才发布文件剪贴板。大文件需要等传输完成再粘贴。
复制文件为复制语义，即便源端使用剪切也不会删除源文件；不自动执行接收的文件。
纯文本上限 8 MiB；一次文件传输总计最多 10 GiB、4096 个文件/目录条目、32 层目录。
不接收符号链接、目录联接、设备路径或越界相对路径；文本以外的富文本和图片格式不由本扩展同步。
新的复制操作会取消过时传输；未完成的临时文件会清理，原有用户文件不会被覆盖。
接收完的文件保留在 %LOCALAPPDATA%\Moonlight-Focus\Clipboard 或 %LOCALAPPDATA%\Sunshine-Focus-Sync\Clipboard。
为了支持稍后粘贴，完成的缓存不会随断线删除。确认已粘贴且剪贴板不再引用后可手动清理这些目录。
不转发连接建立前已有的剪贴板；需要连接后重新复制。客户端断线即停止，服务端未完成上传最多 60 秒清理。
通道复用配对证书验证的 GameStream HTTPS，不增加监听端口；服务端仅允许当前已配对且正在串流的客户端。

六、更新
Moonlight 的软件更新检查已禁用。
Sunshine 控制面板、托盘和网页的软件检查/下载/安装更新均已禁用；自动 DS5 组件替换也停用。
保留手动安装驱动、增强运行库和其他原有工具的功能。后续升级本修改版请手动安装新构建。

七、开发环境
Moonlight 基于 v6.1.0，commit f786e94c7b2f943e24e65d7d74deb539b827fc84。
Foundation Sunshine 基于 v2026.1020.23431.杂鱼，commit 66d27405e43ba1cc5e8c88dda88ba44f06ac56b8。
VS Code 打开根目录 Sunshine-Moonlight.code-workspace；build/environment.json 集中配置工具和源码路径。
客户端使用 Qt 6.8.2 / MSVC 14.42 / Windows SDK 10.0.22621.0；服务端使用独立 MSYS2 UCRT64。控制面板使用项目内 Rust/MSVC，网页使用项目内 Node.js。
build.ps1 仅修改当前构建进程环境，不修改系统 PATH。
工作区中 Ctrl+Shift+B 构建客户端，运行“Build Sunshine Lock Sync”任务构建服务端。
“Build Sunshine Web UI”和“Build Sunshine Control Panel”分别重建网页和控制面板，均由 environment.json 提供路径。
构建所需的 SDK 位于原开发仓库的 .local/toolchain 内（或 environment.json 指定的目录）；仅复制安装包不会复制整套开发工具。
